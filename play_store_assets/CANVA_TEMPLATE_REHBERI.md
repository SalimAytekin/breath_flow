# 🎨 Canva ile Play Store Görselleri - Hızlı Başlangıç

## 🚀 30 Dakikada Hazırla!

### 1️⃣ App Icon (512x512) - 10 Dakika

#### Adım 1: Canva'da Proje Oluştur
1. https://www.canva.com/ adresine git
2. Giriş yap (ücretsiz hesap yeterli)
3. "Özel boyut oluştur" → **512 x 512 piksel**

#### Adım 2: Tasarım Yap
```
Önerilen Tasarım:
┌─────────────────┐
│                 │
│    🌬️ veya     │
│   Nefes İkonu   │
│                 │
│   BreathFlow    │
│                 │
└─────────────────┘
```

**Tasarım Öğeleri:**
- **Arka Plan**: Gradient (Mavi #4A90E2 → Mor #9B59B6)
- **İkon**: Nefes dalgası, akciğer veya spiral
- **Renk Paleti**: 
  - Ana: #4A90E2 (Mavi)
  - İkincil: #9B59B6 (Mor)
  - Vurgu: #FFFFFF (Beyaz)

**Canva'da Nasıl:**
1. Sol menü → "Öğeler"
2. Arama: "breath", "meditation", "wave", "lung"
3. İstediğin ikonu sürükle
4. Arka plan → Gradient ekle
5. Renkler: Mavi-Mor geçişi

#### Adım 3: İndir
- Dosya türü: **PNG**
- Şeffaf arka plan: **AÇIK** (önerilir)
- Kalite: **Yüksek**
- İsim: `icon_512x512.png`
- Kaydet: `play_store_assets/app_icon/`

### 2️⃣ Feature Graphic (1024x500) - 15 Dakika

#### Adım 1: Canva'da Proje Oluştur
1. "Özel boyut oluştur" → **1024 x 500 piksel**

#### Adım 2: Tasarım Layout
```
┌────────────────────────────────────────────────────┐
│  [İkon]  BreathFlow                    [Mockup]   │
│          Zihinsel Huzur ve Nefesin Gücü            │
└────────────────────────────────────────────────────┘
```

**Layout Önerisi:**
```
Sol 1/3:
- Uygulama ikonu (büyük)
- Veya nefes animasyonu görseli

Orta 1/3:
- "BreathFlow" (büyük, bold)
- "Zihinsel Huzur ve Nefesin Gücü" (orta)
- "Nefes • Meditasyon • Uyku" (küçük)

Sağ 1/3:
- Telefon mockup'ı
- Veya uygulama ekranı
```

**Canva'da Nasıl:**
1. Arka plan: Gradient (Mavi-Mor-Siyah)
2. Sol: İkon veya emoji 🌬️
3. Orta: Metin kutuları
   - Başlık: 48-60pt, Bold
   - Alt başlık: 24-32pt, Regular
4. Sağ: Telefon mockup (opsiyonel)
   - Arama: "phone mockup"
   - Veya kendi ekran görüntünü yükle

**Renk Şeması:**
- Arka plan: Gradient (#1a1a2e → #16213e → #0f3460)
- Başlık: Beyaz (#FFFFFF)
- Alt başlık: Açık gri (#E0E0E0)
- Vurgu: Mavi (#4A90E2)

#### Adım 3: İndir
- Dosya türü: **PNG** veya **JPEG**
- Kalite: **Yüksek**
- İsim: `feature_1024x500.png`
- Kaydet: `play_store_assets/feature_graphic/`

### 3️⃣ Screenshot Mockup'ları - 5 Dakika (Her biri)

#### Yöntem A: Basit Mockup (Hızlı)

1. **Ekran görüntülerini al** (emülatör veya gerçek cihaz)
2. **Canva'da proje oluştur**: 1080 x 2400 piksel
3. **Ekran görüntüsünü yükle**: Tam sayfa olarak yerleştir
4. **İndir**: PNG olarak

#### Yöntem B: Telefon Çerçeveli Mockup (Profesyonel)

1. **Mockuphone'a git**: https://mockuphone.com/
2. **Cihaz seç**: Google Pixel 6 Pro
3. **Ekran görüntüsünü yükle**
4. **İndir**: PNG olarak
5. **Canva'da düzenle** (opsiyonel):
   - Arka plan ekle
   - Açıklama metni ekle
   - Özellik vurguları ekle

#### Yöntem C: Açıklamalı Screenshot (En Profesyonel)

**Canva'da:**
1. Proje oluştur: 1080 x 2400 piksel
2. Arka plan: Gradient veya düz renk
3. Ekran görüntüsünü ortaya yerleştir (hafif küçült)
4. Üstte veya altta açıklama metni ekle:
   ```
   🫁 Nefes Egzersizleri
   Rehberli animasyonlarla kolay takip
   ```
5. İndir: PNG

**Önerilen Screenshot Açıklamaları:**

1. **Ana Ekran**: "10+ Bilimsel Nefes Tekniği"
2. **Nefes Egzersizi**: "Rehberli Animasyonlar"
3. **Ses Dünyası**: "20+ Rahatlatıcı Ses"
4. **Mix Panel**: "Kendi Atmosferini Yarat"
5. **Uyku Takibi**: "Uyku Kaliteni Analiz Et"
6. **İstatistikler**: "İlerlemenizi Takip Edin"
7. **Premium**: "Reklamsız Premium Deneyim"
8. **Profil**: "Kişiselleştirilmiş Deneyim"

## 🔧 Canva İpuçları

### Hızlı Kısayollar:
- **Ctrl + D**: Kopyala
- **Ctrl + G**: Grupla
- **Ctrl + Shift + G**: Grubu çöz
- **Alt + Sürükle**: Kopyala ve taşı
- **Ctrl + Z**: Geri al

### Öğeler Menüsü:
- **Şekiller**: Gradient arka planlar
- **Çizgiler**: Ayırıcılar
- **Grafikler**: İkonlar ve illüstrasyonlar
- **Fotoğraflar**: Stok görseller
- **Metinler**: Hazır başlık şablonları

### Renk Paletleri:
1. Canva'da "Renkler" → "Belge renkleri"
2. BreathFlow renkleri ekle:
   - #4A90E2 (Mavi)
   - #9B59B6 (Mor)
   - #1a1a2e (Koyu)
   - #FFFFFF (Beyaz)

## 📱 Ekran Görüntüsü Alma Rehberi

### Android Studio Emülatör:
```bash
1. Emülatörü başlat (Pixel 6 Pro önerilir)
2. Uygulamayı çalıştır
3. Emülatör yan panel → Kamera ikonu
4. "Save" → Konum seç
5. Dosya adı: 01_home.png, 02_breathing.png, vb.
```

### Gerçek Android Cihaz:
```bash
1. Uygulamayı aç
2. Güç + Ses Kısma tuşlarına aynı anda bas
3. Ekran görüntüsü kaydedildi
4. USB ile bilgisayara aktar
5. play_store_assets/screenshots/phone/ klasörüne kopyala
```

### Windows'ta Boyutlandırma:
```powershell
# Paint ile:
1. Resmi aç
2. Yeniden Boyutlandır → Piksel
3. Yatay: 1080, Dikey: 2400
4. Kaydet

# Online araç:
https://www.iloveimg.com/resize-image
```
