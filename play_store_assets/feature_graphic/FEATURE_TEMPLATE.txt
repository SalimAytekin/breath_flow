## 🛠️ Canva ile Oluşturma

### Adım 1: Proje Oluştur
1. https://www.canva.com/ → Giriş yap
2. "Özel boyut oluştur" → 1024 x 500 piksel

### Adım 2: Arka Plan
1. Sol menü → "Öğeler" → "Şekiller"
2. Dikdörtgen seç → Tam sayfa yap
3. Renk → Gradient
4. Tip: Doğrusal (Linear)
5. Renkler: 
   - Sol: #1a1a2e (Koyu)
   - Orta: #16213e
   - Sağ: #0f3460

### Adım 3: Başlık Ekle
1. Sol menü → "Metin" → "Başlık ekle"
2. Metin: "BreathFlow"
3. Font: Montserrat Bold (veya benzeri)
4. Boyut: 60pt
5. Renk: Beyaz (#FFFFFF)
6. Hizalama: Orta
7. Konum: Üst-orta

### Adım 4: Alt Başlık Ekle
1. Sol menü → "Metin" → "Alt başlık ekle"
2. Metin: "Zihinsel Huzur ve Nefesin Gücü"
3. Font: Montserrat Regular
4. Boyut: 28pt
5. Renk: Açık Gri (#E0E0E0)
6. Hizalama: Orta
7. Konum: Başlığın altında

### Adım 5: İkon/Emoji Ekle (Opsiyonel)
**Yöntem A: Emoji**
1. Sol menü → "Metin"
2. Emoji ekle: 🌬️
3. Boyut: Büyük (80-100pt)
4. Konum: Sol üst veya başlığın yanı

**Yöntem B: Canva İkonları**
1. Sol menü → "Öğeler"
2. Arama: "breath", "meditation", "wave"
3. İkon seç
4. Renk: Beyaz veya Mavi
5. Konum: Sol taraf

### Adım 6: Özellikler Ekle (Opsiyonel)
1. Alt kısma 3 emoji ekle:
   - 🫁 Nefes Egzersizleri
   - 🎵 Rahatlatıcı Sesler
   - 😴 Uyku Takibi
2. Her birinin altına küçük metin
3. Eşit aralıklarla yerleştir

### Adım 7: Telefon Mockup Ekle (Opsiyonel - İleri Seviye)
1. Sol menü → "Öğeler"
2. Arama: "phone mockup"
3. Mockup seç
4. Kendi ekran görüntünü yükle
5. Sağ tarafa yerleştir

### Adım 8: İndir
1. Sağ üst → "Paylaş" → "İndir"
2. Dosya türü: PNG (önerilir) veya JPEG
3. Kalite: Yüksek
4. İndir

### Adım 9: Kaydet
- Dosya adı: `feature_1024x500.png`
- Konum: Bu klasör (`play_store_assets/feature_graphic/`)
