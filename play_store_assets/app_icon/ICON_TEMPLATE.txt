## 🛠️ Canva ile Oluşturma

### Adım 1: Proje Oluştur
1. https://www.canva.com/ → Giriş yap
2. "Özel boyut oluştur" → 512 x 512 piksel

### Adım 2: Arka Plan
1. Sol menü → "Öğeler" → "Şekiller"
2. Kare seç → Tam sayfa yap
3. Renk → Gradient
4. Renkler: Mavi (#4A90E2) → Mor (#9B59B6)

### Adım 3: İkon Ekle
**Yöntem A: Canva İkonları**
1. Sol menü → "Öğeler"
2. Arama: "breath", "meditation", "wave", "lung"
3. İstediğin ikonu seç
4. Ortaya yerleştir
5. Renk: Beyaz

**Yöntem B: Emoji**
1. Sol menü → "Metin"
2. Emoji ekle: 🌬️
3. Boyut: Çok büyük (200-300pt)
4. Ortaya yerleştir

### Adım 4: Metin (Opsiyonel)
1. Sol menü → "Metin"
2. "BreathFlow" veya "BF" yaz
3. Font: Bold, Sans-serif
4. Renk: Beyaz
5. Boyut: 48-60pt
6. Alt kısma yerleştir

### Adım 5: İndir
1. Sağ üst → "Paylaş" → "İndir"
2. Dosya türü: PNG
3. Şeffaf arka plan: AÇIK (önerilir)
4. Kalite: Yüksek
5. İndir

### Adım 6: Kaydet
- Dosya adı: `icon_512x512.png`
- Konum: Bu klasör (`play_store_assets/app_icon/`)
