## 🛠️ Video Oluşturma Yöntemleri

### Yöntem 1: Ekran Kaydı (En Kolay)

#### Android Studio Emülatör:
```
1. Emülatörü başlat
2. Uygulamayı çalıştır
3. Emülatör yan panel → "Record Screen"
4. Özellikleri göster (30-60 sn)
5. Durdur ve kaydet
```

#### OBS Studio (Ücretsiz):
```
1. OBS Studio indir: https://obsproject.com/
2. Ekran kaydı ayarla
3. Emülatör veya gerçek cihazı kaydet
4. Video düzenle
5. YouTube'a yükle
```

#### Windows Game Bar:
```
1. Win + G tuşlarına bas
2. Kayıt butonuna tıkla
3. Emülatörü kaydet
4. Win + Alt + R ile durdur
```

### Yöntem 2: Video Düzenleme (Profesyonel)

#### CapCut (Ücretsiz, Kolay):
```
1. CapCut indir (PC veya mobil)
2. Ekran kayıtlarını içe aktar
3. Müzik ekle (telif hakkı yok)
4. Metin overlay'leri ekle
5. Geçişler ekle
6. Export → 1080p
7. YouTube'a yükle
```

#### DaVinci Resolve (Ücretsiz, Profesyonel):
```
1. DaVinci Resolve indir (ücretsiz)
2. Proje oluştur (1920x1080, 30fps)
3. Ekran kayıtlarını düzenle
4. Müzik ve efektler ekle
5. Export → YouTube preset
6. YouTube'a yükle
```

FPS: 30 veya 60
Codec: H.264
