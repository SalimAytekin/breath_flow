# 📱 Telefon Ekran Görüntüleri Checklist

## ✅ Gereksinimler
- **Adet**: Minimum 2, Maksimum 8 (4-8 önerilir)
- **Boyut**: 1080 x 2400 piksel (veya 1080 x 1920)
- **Format**: PNG veya JPEG
- **Maksimum Dosya Boyutu**: 8 MB
- **En Boy Oranı**: 9:16 (dikey)

## 📐 Boyutlandırma

### Emülatörden Alınan Ekran Görüntüleri:
```
Orijinal: 1440 x 3120 (Pixel 6 Pro)
Hedef: 1080 x 2400
```

### Gerçek Cihazdan Alınan:
```
Değişken boyutlar
Hedef: 1080 x 2400 veya 1080 x 1920
```

### Boyutlandırma Araçları:
- **PowerShell Script**: `resize_screenshots.ps1`
- **Online**: https://www.iloveimg.com/resize-image
- **Paint**: Yeniden Boyutlandır → Piksel
- **ImageMagick**: `magick convert input.png -resize 1080x2400 output.png`
